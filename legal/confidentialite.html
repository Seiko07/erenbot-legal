Politique de confidentialité d’Eren

Dernière mise à jour : 28 octobre 2026

Qui exploite Eren ?

Eren est un bot Discord exploité par son propriétaire. Pour toute question sur cette politique, une demande de suppression ou l’exercice d’un droit relatif aux données, contacte le responsable via son profil Discord.

Données traitées

  • Les identifiants Discord des utilisateurs, serveurs, salons et rôles nécessaires à l’exécution des commandes et à l’administration du bot.
  • Le contenu des messages qui commencent par le préfixe configuré, afin de reconnaître la commande et ses paramètres. Le bot ne conserve pas les messages de commande ordinaires dans ses fichiers de données.
  • Les informations de modération enregistrées à la demande des administrateurs : notes, avertissements et autres sanctions, motifs, identifiants et noms Discord des personnes concernées et des modérateurs, pseudos verrouillés, ainsi que les échéances de sanctions temporaires.
  • Les identifiants des personnes autorisées à utiliser ou gérer le bot (owners et buyers), ainsi que les identifiants des emojis de catégories du menu d’aide.
  • Pour +dmall, la liste des membres humains du serveur et le texte rédigé par le modérateur sont traités pour préparer l’aperçu puis envoyer le message après confirmation. Cette opération n’enregistre pas le texte dans les fichiers de données du bot.
  • Pour les commandes musicales, le lien fourni est utilisé pour rechercher ou lire le contenu public demandé. Les plateformes source, par exemple YouTube ou TikTok, peuvent recevoir les requêtes nécessaires à la lecture selon leurs propres règles.

Pourquoi ces données sont-elles utilisées ?

Eren utilise ces informations pour répondre aux commandes, appliquer les réglages et actions de modération demandés par les personnes autorisées, maintenir les accès au bot, gérer les fonctions de musique et transmettre les messages privés confirmés par un modérateur. Eren ne vend pas ces données et n’utilise pas de publicité ou d’analyse d’audience dans le code fourni.

Stockage et durée de conservation

Les listes d’accès et données de modération sont conservées dans les fichiers data/access.json et data/moderation.json sur la machine qui héberge le bot. Les notes et l’historique des sanctions restent enregistrés jusqu’à leur suppression par un administrateur ou jusqu’à la suppression des fichiers. Les commandes de gestion permettent notamment de supprimer des notes et sanctions. Les accès peuvent être retirés avec les commandes de gestion owners/buyers. Les tempbans actifs sont retirés du suivi après leur échéance ; les timeouts expirés sont nettoyés lors de leur consultation ou lorsqu’ils sont levés. L’historique correspondant reste conservé jusqu’à sa suppression. Les données de lecture musicale restent en mémoire et disparaissent lorsque la lecture s’arrête ou que le bot redémarre.

Partage

Les données sont transmises à Discord lorsque cela est nécessaire au fonctionnement du bot et aux actions demandées dans Discord. Les liens musicaux sont traités par les plateformes concernées pour obtenir le contenu demandé. Eren n’envoie pas les fichiers locaux de données à ces plateformes.

Visite de ce site

Les présentes pages sont hébergées par GitHub Pages. GitHub indique que l’adresse IP des visiteurs de ses sites Pages est enregistrée et conservée à des fins de sécurité. Consulte la déclaration de confidentialité de GitHub pour plus d’informations.

Demandes relatives aux données

Un membre peut demander au propriétaire du serveur de supprimer les notes ou entrées d’historique de sanctions le concernant, lorsque ces fonctions sont disponibles. Pour une demande portant sur les autres fichiers ou pour une question sur les données, contacte le responsable d’Eren via son profil Discord. Les données conservées par Discord ou par les plateformes musicales relèvent également de leurs propres politiques et outils.

Sécurité et modifications

Les fichiers sont stockés sur l’ordinateur ou le serveur choisi par l’exploitant du bot. La sécurité de cette machine et les sauvegardes relèvent de son exploitant. Cette politique pourra être mise à jour si le fonctionnement ou les données traitées par Eren changent ; la date en haut de page sera alors actualisée.
